# Meu Portfólio Pessoal

## Sobre o projeto

Este projeto foi desenvolvido como atividade da faculdade, com o objetivo de criar um portfólio pessoal utilizando React e Vite.

A página apresenta um pouco sobre mim, minhas habilidades na área de programação e alguns projetos que desenvolvi durante meus estudos de Análise e Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite

## Organização do projeto

O projeto foi separado em componentes para facilitar a organização e a manutenção do código.

- **Header.jsx:** responsável pelo cabeçalho da página.
- **Sobre.jsx:** apresenta algumas informações pessoais.
- **Habilidades.jsx:** mostra as tecnologias que estou aprendendo.
- **Projetos.jsx:** apresenta alguns projetos desenvolvidos durante a faculdade.
- **App.jsx:** reúne os componentes principais.
- **App.css:** contém os estilos da página.
